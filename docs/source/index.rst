Welcome to wayve's documentation!
=================================

For new users, the scripts in the example folder showcase the general structure of the code and the simulation workflow.

Wake model developers interested in coupling their code to WAYVE can find the necessary information in `the second example script <https://gitlab.kuleuven.be/TFSO-software/wayve/-/blob/main/examples/02_wind_farm.py>`_ and `the base class for the wake model interface. <https://gitlab.kuleuven.be/TFSO-software/wayve/-/blob/main/wayve/forcing/wind_farms/wake_model_coupling/wake_model_interface.py>`_
