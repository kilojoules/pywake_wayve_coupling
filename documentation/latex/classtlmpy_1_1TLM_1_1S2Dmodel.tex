The exact value doesn't matter because it does not appear in the system of equations (the continuity equation changes to an incompressiblity condition in the limiting case) The value of eta1,2 is replaced with the limit value p1,2/PHI to make the eta field continuous. Note that setting eta1,2 to zero would cause broad stripes in the solution field when one of U1,V1,U2,V2 is zero.
